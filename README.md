# 한글뜰 1.1 · SteamVR 한글 키보드

만든이: **협합**  
문제나 오류, 피드백은 디스코드 **suin__ (언더바 두 개)**으로 문의 바랍니다.

기존 한글뜰의 PC 창을 종료한 다음 `start-vr.cmd` 또는 `dist/HangeulVR-1.1.exe`를 실행하세요. ZIP 배포본에서는 `HangeulVR-1.1.exe`를 실행합니다. DLL과 JSON 파일은 실행 파일 옆에 유지하세요.

Windows x64, .NET Framework 4.x, SteamVR이 필요합니다. VRChat은 SteamVR 모드로 실행하고 액션 메뉴의 OSC → Enabled를 켜세요.

## 0.10 디자인

입력칸을 둥근 카드로 정리하고 메시지 제목·실시간 공유 상태·글자 수를 안쪽에 배치했습니다. 본문 글자를 키우고 안내 문구를 아래에 분리했습니다. 키와 버튼의 모서리·색상을 통일하고 활성 기능과 완료 버튼을 강조했습니다. 설정 화면도 같은 스타일을 사용합니다.

## 0.9 설정 화면

오른쪽 위 **설정**을 누르면 자판 대신 불투명도·크기 슬라이더가 표시됩니다. **키보드로**를 누르면 작성 중인 내용을 유지한 채 돌아옵니다. 하단 조절 줄과 모서리 크기 버튼은 제거했습니다. 양손 그립 크기 조절은 그대로 사용할 수 있습니다.

## 0.8 추가 기능

- 한 손 그립으로 창을 잡은 상태에서 다른 손 그립도 누르면 양손 크기 조절을 시작합니다. 손을 벌리면 확대, 모으면 축소합니다. 두 손은 처음에 8cm 이상 떨어뜨려 주세요.
- 양손 크기 조절 중 창 중심은 고정됩니다. 한 손을 놓으면 남은 손으로 이동을 이어가고, 모두 놓으면 고정합니다. 크기는 저장됩니다.
- Ctrl을 켜면 A/C/V/X/Z/Y 키에 전체 선택·복사하기·붙여넣기·잘라내기·되돌리기·다시 실행 이름이 표시됩니다.

## 변경 사항

- 모두 지움과 호출 설정 버튼을 제거했습니다.
- 호출은 **왼손 그립을 잡은 채 오른손 트리거 두 번**으로 고정했습니다. 두 번 누르는 간격은 0.45초 이내입니다. 이전 호출 설정은 적용하지 않습니다.
- 제목을 트리거로 잡는 대신, **열린 키보드 어디든 가리키고 어느 손이든 그립을 누르면 이동·회전**합니다. 놓으면 고정됩니다.
- 소환할 때 이미 잡고 있던 그립은 한 번 놓았다 다시 잡아야 이동을 시작합니다. 이동 중에는 타이핑을 막습니다.
- 단축어 줄과 큰 방향키 줄을 제거하고, 기존 물음표와 모두 지움 공간에 작은 방향키 묶음을 배치했습니다.
- 전체 이미지 높이를 760에서 640으로 줄였습니다. 글자 키 크기는 유지합니다.
- 물음표는 Shift를 켠 뒤 `/` 키로 입력합니다. 되돌리기와 다시 실행은 Ctrl+Z / Ctrl+Y를 사용하세요.

## 편집과 조절

컨트롤러로 가리키고 트리거로 입력합니다. Shift는 다음 글자에 적용하고 Caps Lock은 영문 대문자를 유지합니다. 한/영 버튼으로 언어를 바꿉니다.

Ctrl을 누른 뒤 A/C/X/V/Z/Y를 누르면 전체 선택/복사/잘라내기/붙여넣기/되돌리기/다시 실행입니다. 복사와 붙여넣기는 Windows 클립보드를 사용합니다. Ctrl은 단축키 사용 후 풀립니다.

좌우 방향키는 글자 사이를 이동합니다. 위아래 방향키는 직접 줄바꿈한 줄 사이를 이동하며 화면 너비에 따른 자동 줄바꿈 기준 이동은 지원하지 않습니다. Shift+방향키로 선택 영역을 확장합니다. 선택 후 입력하면 해당 영역을 바꿉니다. 방향키와 Backspace를 길게 누르면 반복됩니다.

설정 화면의 슬라이더로 불투명도 25~100%, 실제 너비 0.55~1.80m를 조절합니다. 양손 그립으로도 크기를 변경할 수 있습니다. 크기와 불투명도는 EXE 옆 `user-settings.json`에 저장됩니다. 기존 단축어 저장 데이터는 파일에 남지만 화면에서는 사용하지 않습니다.

닫기 또는 호출 동작으로 창을 닫으면 초안, 선택 영역, Shift/Caps/Ctrl, 편집 이력, 대기 전송을 초기화합니다. 설정은 유지합니다.

## 채팅

**실시간 전송은 기본으로 켜져 있으며 작성 중인 내용도 다른 사람에게 보입니다.** 상단 실시간 버튼으로 끌 수 있습니다.

첫 변경은 약 0.25초 후, 이후에는 최소 1.5초 간격으로 최신 문장을 보냅니다. 작성 완료/Enter는 최신 문장을 전송한 뒤 초안을 비웁니다. 전송 간격이 남으면 대기하며, 기다리는 중 편집하거나 닫으면 완료 대기를 취소합니다. 줄바꿈은 줄바꿈 버튼 또는 Shift+Enter입니다.

최대 144 UTF-16 코드 단위, 직접 줄바꿈 최대 9줄입니다. 빈 문장은 보내지 않습니다. 이미 VRChat에 표시된 말풍선은 창을 닫아도 게임의 표시 시간 동안 남을 수 있습니다.

OSC 대상은 `127.0.0.1:9000`이며 `OSC_PORT` 환경 변수로 변경할 수 있습니다. UDP 전송 성공이 게임 수신을 보장하지는 않습니다.

## 장치와 검증

Quest/Oculus Touch, Index, Vive, Windows MR 기본 바인딩을 제공합니다. Index 그립은 쥐는 힘이 필요합니다. 입력이 안 되면 PC 창의 컨트롤러 바인딩 설정을 확인하세요. SteamVR 대시보드를 열면 입력·전송·이동을 중단합니다. VRChat 자체의 컨트롤러 동작을 차단하지는 않습니다.

입력 확인 목표는 180~288Hz, 화면 갱신 목표는 60~144Hz입니다. 실제 FPS를 보장하는 수치가 아닙니다. 동일한 Direct3D 텍스처와 자판 캐시를 사용합니다.

자동 테스트는 한글 조합, 커서·선택, 단축키, 초기화, 설정 저장, 이동 좌표, OSC 루프백, 전송 간격, 렌더링을 확인합니다. 실제 헤드셋에서 그립 이동과 조작감을 확인해야 합니다.

```powershell
.\build-vr.ps1 -IncludeDevTools
& '.\dist\HangeulVR-DevTools.exe' --self-test "$PWD\native-test-results.txt" | Out-Null
Get-Content native-test-results.txt
```

빌드는 Node.js(바인딩 생성)와 Windows .NET Framework C# 컴파일러를 사용합니다. OpenVR 출처와 라이선스는 `vendor/README.md`, `vendor/OpenVR-LICENSE.txt`에 있습니다.

`HangeulVR-DevTools.exe --preview`는 개발용 PC 미리보기입니다. 배포 EXE에는 개발용 명령이 없습니다. VR 이동·크기·불투명도는 SteamVR에서 확인하세요. 미리보기에서도 입력 내용을 OSC로 보냅니다.

이전 웹 버전은 `start-web.cmd` 또는 `npm start` 후 http://127.0.0.1:18741 에서 실행합니다. Node.js 20 이상이 필요합니다.

## 1.0 보안 보강

배포 EXE에서 테스트·벤치마크·이미지 출력·미리보기 코드를 분리했습니다. DLL 검색은 프로그램 폴더와 Windows 시스템 폴더로 제한하며, 시스템 DLL은 System32에서만 불러옵니다. OpenVR DLL은 고정 SHA-256을 확인하고 앱 실행 동안 파일 교체를 막습니다. 변경된 DLL은 불러오지 않고 오류를 표시합니다.

정식 코드 서명은 아직 적용되지 않았습니다.


## 1.1 자동 실행·업데이트

PC 창에서 SteamVR 시작 시 자동 실행을 켜거나 끌 수 있습니다. 기본은 꺼짐입니다. SteamVR 연결 시 협합 · 한글뜰을 시작 오버레이 앱 목록에 등록하고, SteamVR에서 바꾼 On/Off도 반영합니다. Windows Run 등록과 VRChat 감시 프로그램은 사용하지 않으며, 이전 Windows 시작 등록은 제거합니다. 기존 자동 실행 ON 설정은 한 번만 SteamVR로 이전합니다. 업데이트 후 실행 경로를 갱신하면서 SteamVR의 On/Off는 보존합니다.

업데이트는 공개 GitHub Releases를 사용합니다. 저장소가 연결되면 시작 시 및 6시간마다 확인하고, 새 버전 알림과 설치 버튼을 표시합니다. RSA-SHA256으로 서명한 update.json과 update.json.sig, SHA-256이 일치하는 ZIP만 설치하며 업데이트 URL은 GitHub HTTPS로 제한됩니다. 버전별 폴더에 설치하므로 기존 EXE를 덮어쓰지 않습니다. 배포처와 서명 키 관리는 UPDATE-PUBLISHING.md를 참고하세요.
