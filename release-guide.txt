한글뜰 1.1.9 — SteamVR 한글 채팅 키보드

[처음 실행]
1. ZIP을 원하는 폴더에 전부 압축 해제하세요. ZIP 안에서 바로 실행하지 마세요.
2. SteamVR과 VRChat을 실행하세요. Virtual Desktop도 SteamVR 모드로 실행하세요.
3. VRChat 액션 메뉴에서 OSC → Enabled를 켜세요.
4. HangeulVR-1.1.9.exe를 실행하세요.
   이전 한글뜰이 실행 중이면 먼저 PC 제어 창을 닫으세요.

Windows x64, .NET Framework 4.x, SteamVR이 필요합니다.
별도 설치나 Node.js는 필요 없습니다. DLL과 JSON 파일을 EXE 옆에 유지하세요.

[기본 조작]
- 열기/닫기: 왼손 그립을 잡고 오른손 트리거 두 번 (0.45초 이내).
- 입력: 컨트롤러로 키를 가리키고 트리거.
- 이동: 창을 가리키고 한 손 그립으로 잡아 이동. 놓으면 고정.
- 크기: 한 손으로 잡은 뒤 다른 손도 그립을 누르고, 두 손을 벌리거나 모으기.
  시작할 때 손 사이를 8cm 이상 띄우세요.
- 설정: 오른쪽 위 설정 → 불투명도·크기 조절. 키보드로 버튼으로 복귀.
- 한/영: 아래쪽 한/영 버튼.
- 물음표: Shift를 켜고 / 키.
- 줄바꿈: 줄바꿈 버튼 또는 Shift+Enter.
- 커서 이동: 오른쪽 아래 방향키. Shift+방향키로 선택.
- Ctrl을 켜면 복사하기·붙여넣기 등 기능 이름이 표시됩니다.
  A 전체 선택 / C 복사 / X 잘라내기 / V 붙여넣기 / Z 되돌리기 / Y 다시 실행.
- 완료: 작성 완료 또는 Enter.
- 종료: PC 제어 창을 닫으세요.

[채팅과 저장]
실시간 공유는 기본으로 켜져 있습니다. 작성 중인 문장도 다른 사람에게 보입니다.
원하지 않으면 위쪽 실시간 버튼을 끄고 작성 완료로 전송하세요.
변경된 문장은 최소 1.5초 전송 간격을 지킵니다.
최대 144 UTF-16 코드 단위, 직접 줄바꿈 최대 9줄입니다.
키보드를 닫으면 초안·Shift·Caps·Ctrl·편집 이력·대기 전송을 초기화합니다.
이미 게임에 표시된 말풍선은 VRChat의 표시 시간 동안 남을 수 있습니다.
크기와 불투명도는 실행 폴더의 user-settings.json에 저장됩니다.
오류 진단 파일은 overlay.log입니다.

[입력이 안 될 때]
SteamVR 연결과 VRChat의 OSC Enabled를 확인하세요.
기본 컨트롤러: Quest/Oculus Touch, Index, Vive, Windows MR.
기존 개인 바인딩을 사용 중이라면 PC 창의 컨트롤러 바인딩 설정에서 기본 바인딩을 확인하세요.
대시보드가 열린 동안에는 입력과 전송이 멈춥니다.
VRChat 자체의 컨트롤러 입력을 차단하지는 않습니다.

OSC 기본 대상: 127.0.0.1:9000. OSC_PORT 환경 변수로 변경할 수 있습니다.
이 앱은 SteamVR 오버레이이며 VRChat의 기본 키보드를 교체하지 않습니다.
기기별 실제 조작감과 VRChat 수신은 사용 환경에서 확인이 필요합니다.

OpenVR 출처와 라이선스: OpenVR-LICENSE.txt, THIRD-PARTY.txt

[1.1 보안 보강]
개발용 테스트 기능을 배포 EXE에서 분리했습니다.
DLL 검색 경로를 제한하고, OpenVR DLL이 배포본과 같은 파일인지 확인합니다.
DLL이 다르다는 오류가 나오면 다른 DLL로 교체하지 말고 배포본을 다시 받아 주세요.




[SteamVR 자동 실행]
SteamVR을 켠 상태에서 한글뜰을 한 번 실행하면 시작 오버레이 앱 목록에 등록됩니다.
PC 제어 창에서 SteamVR 시작 시 한글뜰 자동 실행을 켜세요. 기본은 꺼짐입니다.
SteamVR 설정 → 시작/종료 → 시작 오버레이 앱에서 협합 · 한글뜰의 On/Off로도 변경할 수 있습니다.
SteamVR이 꺼져 있으면 앱에서 고른 설정을 다음 연결 때 적용합니다.
Windows 로그인 대기 프로그램은 사용하지 않습니다. 기존 Windows 시작 등록은 제거됩니다.
이전 자동 실행을 켰던 경우 한 번만 SteamVR 자동 실행으로 옮깁니다.
자동 업데이트 후 새 버전을 실행하면 SteamVR 등록 경로도 갱신됩니다.
수동으로 폴더를 옮겼다면 옮긴 위치에서 한 번 실행하세요. 등록한 폴더는 삭제하지 마세요.

[업데이트]
앱을 열 때와 6시간마다 공식 GitHub Releases의 서명된 버전 정보를 자동 확인합니다.
새 버전이 없으면 "현재 최신버전입니다", 새 버전이 있으면 "이전 버전입니다"를 표시합니다.
인터넷 연결 등으로 확인하지 못하면 "버전을 확인할 수 없습니다"를 표시합니다.
새 버전이 있으면 앱 시작 시 업데이트하기 / 나중에하기를 표시합니다.
업데이트하기를 누르면 검증 후 별도 폴더에 설치하고 설정을 복사한 뒤 재시작합니다. 나중에하기는 다음 실행 시 다시 안내합니다. 설치 실패 시 기존 폴더는 유지됩니다. 다운로드 중에는 창을 닫지 마세요.
[1.1.7 실행 경로 보강]
ZIP 안에서 직접 실행하지 말고 전체를 문서 등의 고정 폴더에 압축 해제하세요.
임시 폴더에서는 설정 저장·시작 등록·VR 연결 전에 안내하고 종료합니다.
SteamVR의 자동 시작 상태를 보존하며, 사용자가 앱이나 SteamVR에서 ON/OFF를 바꿀 수 있습니다.
이 수정은 Defender 오탐 해제나 미탐지를 보장하지 않습니다. 차단되면 격리를 유지하세요.

[1.1.7 SteamVR 시작 수정]
바탕 화면 등 한글 경로를 SteamVR이 직접 실행하지 못하는 경우를 해결했습니다.
LocalAppData의 HangeulVR/steamvr-launcher에 실행 파일의 동일한 사본을 두고, 이 사본이 원래 폴더의 앱을 실행한 뒤 즉시 종료합니다. 상주 감시 프로그램은 아닙니다.

[1.1.7 개선]
- 채팅 글자 사이를 컨트롤러로 가리키고 트리거를 누르면 커서가 이동합니다.
- 설정에서 잡고 조이스틱으로 거리 조절을 켜면, 한 손 그립으로 창을 잡고 해당 손의 스틱을 위로 밀어 멀리, 아래로 당겨 가까이 옮깁니다. 기본은 꺼짐이며 설정은 저장됩니다. 양손 크기 조절 중에는 거리가 변하지 않습니다.
- 설치된 최신 버전을 우선 실행하여 구버전으로 돌아가는 문제를 수정했습니다. 1.1.6 이하 실행 파일에는 이 수정이 없으므로, 처음 1.1.7로 전환할 때는 새 실행 파일을 사용하세요. 이후 업데이트에서는 원래 실행 경로도 새 버전에 연결됩니다.

[1.1.8 업데이트 유지 수정]
1.1.3 등에서 업데이트하여 기존 실행 경로 정보가 없는 경우, 새 버전 첫 실행 시 평소 사용하던 이전 한글뜰 EXE를 한 번 선택합니다. 이전 실행 파일은 백업하고 최신 설치본으로 연결합니다. 취소하거나 파일을 교체하지 못하면 안내 메시지가 표시됩니다.

[1.1.9 거리 유지]
창을 잡아 이동하거나 조이스틱으로 조절한 거리를 저장합니다. 키보드를 다시 열면 현재 바라보는 방향에 저장된 거리로 나타납니다. 프로그램을 재실행해도 유지됩니다. 조이스틱 거리 조절 설정의 기본값은 계속 꺼짐입니다.
